## 1. 目标与范围

把当前占位页替换为郭世尧的个人简历单页站，求职导向。范围仅限前端静态页：

- **做**：单页简历（铭牌栏 / Hero+3D 设备 / 项目经历 / 教育经历 / 技能面板 / 联系底座）。
- **不做**:博客、文章列表、任何新增后端接口、构建工具链、外部 CDN/字体依赖。

后端仅消费既有 `GET /api/health` 用于状态灯，不新增 API。

## 2. 技术选型

纯静态、零构建：

```
nginx/html/
  index.html          # 全部内容,语义化单页
  assets/css/main.css # 设计 token + 四级深度体系 + 组件
  assets/js/main.js   # 状态灯轮询 / 手机号点击显示 / 屏幕打字效果
```

- 部署方式不变：`nginx/html` 卷挂载，git pull 即生效，无需重启容器。
- 零外部依赖：不引 CDN、不下 web 字体，全部系统字体栈，离线可部署。
- 字体栈：正文/标题 `system-ui, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`；数字/铭牌/技术元数据 `ui-monospace, "SF Mono", "Cascadia Mono", Consolas, monospace`（大写 + 宽字距）。
- 语言：全站中文（铭牌元数据为英文等宽标签，属风格元素）。

## 4. 视觉 token

| 角色 | 值 | 用途 |
|---|---|---|
| 底盘 | `#D6D9DC` | 页面背景，哑光塑料 |
| 面板 | `#E9EBED` | 卡片/铭牌 |
| 凹陷 | `#C4C8CC` | 屏幕、输入区 |
| 炭黑面板 | `#22252A` | 技能面板等暗色呼吸区 |
| 文字 | `#2B2E33` | 正文与标题 |
| 安全橙红 | `#E8491D` | 仅按钮、LED、LIVE 标签 |

- 四级深度（凹陷 < 底盘 < 面板 < 悬浮）全部用左上亮/右下暗成对双向阴影表达，**不用边框**；圆角 6–10px 注塑感。
- 全局噪点：inline SVG `feTurbulence` data-URI 叠加层，不引入图片文件。
- 纹理（碳纤维、扫描线）只出现在设备模型与炭黑面板，不全面铺开。

## 5. 交互与动效

- 按钮 `:active`：下移 1–2px + 外凸阴影翻转为内凹，过渡 <100ms（机械开关感）。
- 卡片 `:hover`：抬升 + 阴影加强，cubic-bezier 带过冲的弹簧微回弹。
- LED：呼吸脉动 + 光晕（box-shadow 扩散）。
- CRT 屏幕：扫描线缓慢滚动 + 打字循环。
- `prefers-reduced-motion: reduce` 时所有动效降级为静态。
- 所有可交互元素有可见 `:focus-visible` 样式。
- 图片灰度→彩色规则本站无位图图片，不适用（设备模型为纯 CSS)。

## 6. 响应式

- 桌面（≥720px)：不对称网格，项目区两列错位，卡片 ±1° 微旋转。
- 移动（<720px)：单列堆叠，按钮全宽，设备模型缩小居中；**物理隐喻全部保留**；触控目标 ≥44px；区块留白不减。

## 7. 错误与降级

- `/api/health` 不可达/非 ok：状态灯显示 OFFLINE，页面其余部分正常（静态内容无运行时依赖）。
- JS 禁用：页面完整可读；状态灯显示静态"未知"态，手机号不显示（遮蔽态即最终态），锚点导航仍可用。
- 打字效果失败不影响屏幕静态内容（先渲染静态文本，JS 只做增强）。
